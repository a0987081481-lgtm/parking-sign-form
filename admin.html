公版維護

停車場設備功能測試完成簽認單

這裡不用碰 JSON，直接用表單改標題、欄位和設備項目就能更新所有人的公版頁面。

維護連線

預設走 Worker API，GitHub 直連藏在進階設定裡。

未設定

填入 Worker 後，儲存就會同步到所有人的公版頁面。

進階設定

只有 Worker 還沒建好，或要暫時直連 GitHub 時才需要這裡。

公版標題

這就是公版頁最上面的名稱，儲存後所有人重新整理都會看到。

核心基本欄位

`案場名稱` 和 `場地代號` 會保留，不會讓人誤刪。

可編輯基本欄位

需要的話可以新增其他欄位，名稱與型態都能直接改。

設備類型

每一種設備都可以直接改名稱、調整項目，或新增新的類型。
